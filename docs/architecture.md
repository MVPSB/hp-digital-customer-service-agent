# 系统架构与技术选型

## 整体架构

```
用户输入
  │
  ▼
┌─────────────────────────────────────────┐
│         问题分类 LLM (意图识别)           │
│  consulting / complaint / tech_support  │
│  chitchat / unknown                     │
└─────────────────┬───────────────────────┘
                  │
        ┌─────────┼─────────┬──────────┬─────────┐
        ▼         ▼         ▼          ▼         ▼
    产品咨询    物流咨询   店铺政策   促销活动    投诉/技术支持
        │         │         │          │         │
        ▼         ▼         ▼          ▼         ▼
   知识检索1  参数提取   知识检索3  知识检索4  知识检索5/6
   +库存MCP  +物流MCP                          
        │         │
        ▼         ▼
   回答LLM    回答LLM
        │         │
        └─────────┴──────────► 统一输出
```

## 技术选型决策

### 1. 编排引擎：Dify Chatflow

**选择理由**：
- 可视化流程编排，降低开发门槛
- 内置知识库、工具调用、条件分支等节点
- 支持 API 调用，便于自动化评测
- 活跃的开源社区

**替代方案对比**：
| 方案 | 优势 | 劣势 |
|------|------|------|
| Dify | 可视化、内置RAG、API完善 | 自定义灵活性有限 |
| Coze | 插件生态丰富 | 企业版收费，数据在云端 |
| LangChain | 灵活性最高 | 代码量大，无可视化 |
| 纯Python | 完全可控 | 开发成本高，无管理界面 |

### 2. 大语言模型：DeepSeek V4 Flash

**选择理由**：
- 成本极低（输入1元/百万Token，输出2元/百万Token）
- 中文理解能力强
- 响应速度快，适合客服场景
- 支持长上下文（1M tokens）

**成本估算**：
- 单条对话平均消耗约2000 Token
- 单次对话成本约0.003-0.005元
- 1000条/天约3-5元，月成本约90-150元

### 3. 向量嵌入模型：BAAI/bge-large-zh-v1.5

**选择理由**：
- 中文语义理解优秀
- 开源免费，可本地部署
- 在CMTEB中文榜单排名靠前

**分段策略**：父子分段 (Parent-Child Chunking)
- 子分段：用于检索，粒度细，召回精准
- 父分段：用于LLM阅读，上下文完整
- 解决了618促销等短文本召回失败问题

### 4. 工具协议：MCP (Model Context Protocol)

**选择理由**：
- 标准化工具调用协议，跨平台兼容
- Dify原生支持
- 独立部署，与主应用解耦

**两个MCP服务**：
| 服务 | 端口 | 功能 | 输入 | 输出 |
|------|------|------|------|------|
| stock_mcp_server | 8000 | 库存查询 | product_name | 库存数量、发货仓 |
| logistics_mcp_server | 8001 | 物流查询 | order_number | 快递商、运单状态、位置 |

## 关键技术问题与解决方案

### 问题1：MCP返回格式不兼容
**现象**：物流查询返回`json.dumps()`时，Dify将内容放入`json`字段，`text`字段为空，LLM引用`{{query_logistics.text}}`读到空白。

**解决方案**：将MCP返回改为格式化纯文本，确保Dify的`text`字段有内容。

### 问题2：Docker跨主机访问403
**现象**：Dify运行在Docker容器中，访问宿主机MCP服务返回403 Forbidden。

**解决方案**：关闭MCP服务的"动态客户端注册"，手动填写客户端ID和密钥，使用`host.docker.internal`访问宿主机。

### 问题3：短文本召回失败
**现象**："618有什么活动"无法召回知识库中"618年中大促活动"分段。

**解决方案**：从通用分段升级为父子分段，切换嵌入模型为BAAI/bge-large-zh-v1.5，45个父分段全部索引成功。
