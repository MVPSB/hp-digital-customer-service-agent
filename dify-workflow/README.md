# Dify 工作流导出

## 如何导出工作流

1. 打开 Dify 工作室，进入「客服改」Chatflow 应用
2. 点击右上角「...」→「导出」
3. 选择导出格式（推荐 YAML 或 JSON）
4. 将导出的文件放入本目录，命名为 `workflow.yaml` 或 `workflow.json`

## 工作流节点清单

| 节点类型 | 节点名称 | 功能 |
|---------|---------|------|
| 开始 | 开始 | 用户输入入口 |
| LLM | 问题分类 | 意图识别（5分类） |
| 条件分支 | IF/ELSE | 按意图路由到不同分支 |
| 知识检索 | 知识检索 1~6 | 各场景知识库检索 |
| LLM | 商品信息提取 | 提取产品名称 |
| LLM | 参数提取器2 | 提取订单号/运单号 |
| 工具 | QUERY_STOCK | 库存MCP调用 |
| 工具 | QUERY_LOGISTICS | 物流MCP调用 |
| LLM | 产品咨询回答 | 产品咨询回答生成 |
| LLM | 物流咨询回答 | 物流咨询回答生成 |
| LLM | 店铺政策咨询回答 | 店铺政策回答生成 |
| LLM | 促销活动回答 | 促销活动回答生成 |
| LLM | 投诉回答 | 投诉处理回答生成 |
| LLM | 技术支持回答 | 技术支持回答生成 |
| LLM | 闲聊回答 | 闲聊回答生成 |
| 直接回复 | 直接回复2 | 兜底澄清 |
| 结束 | 结束 | 统一输出 |

## 导入说明

1. 在 Dify 工作室点击「创建应用」→「导入 DSL」
2. 选择本目录下的工作流文件
3. 导入后需要重新配置：
   - 知识库绑定（知识检索节点需绑定你的知识库）
   - MCP工具连接（需先在「工具 → MCP」中添加服务）
   - LLM模型选择（选择DeepSeek V4 Flash）
